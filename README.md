# 小智枝叶文件管理器 v1.0

一款面向 Windows 的思维导图式本地文件管理器。它直接浏览和管理电脑磁盘中的真实文件，不需要导入或复制到专用数据库。

## 主要功能

- 以树状思维导图展示磁盘、文件夹和文件
- 支持展开、收起、缩放、画布拖动、小地图和节点定位
- 支持移动、复制、剪切、粘贴、重命名、新建和安全回收
- 支持 `Ctrl + Z` 撤销与最近操作记录
- 支持 `Ctrl` 多选、`Shift` 框选及批量文件操作
- 大型目录分页加载、缩略图缓存与磁盘变化监听
- 支持固定重要节点的位置
- 使用 Windows 文件图标、属性窗口和同名文件冲突处理
- 支持全目录搜索，并按类型、大小和修改日期筛选
- 支持收藏和多个图谱工作区

## 开发环境

- Windows 10 或 Windows 11
- Node.js 20 或更高版本
- npm

## 本地运行

```powershell
npm install
npm start
```

## 编译便携版 EXE

```powershell
npm run dist
```

生成的程序位于 `release/小智枝叶文件管理器-v1.0.exe`。

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + C` | 复制所选项目 |
| `Ctrl + X` | 剪切所选项目 |
| `Ctrl + V` | 粘贴到所选文件夹 |
| `Ctrl + Z` | 撤销最近文件操作 |
| `Ctrl + 单击` | 多选项目 |
| `Shift + 拖动` | 框选项目 |
| `Alt + 拖动` | 固定节点位置 |
| `F2` | 重命名 |
| `Delete` | 安全回收 |
| `F5` | 刷新图谱 |

## 文件操作说明

软件管理的是磁盘中的真实文件。移动、重命名、复制、新建和回收等操作会直接影响本地文件，请在重要目录中操作前做好备份。
